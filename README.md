# سجل دخول و خروج العمال

## النشر على GitHub Pages
1. أنشئ حسابًا على github.com ثم New repository باسم مثل `attendance` (عام Public).
2. Add file > Upload files، وارفع **كل** ملفات هذا المجلد (index.html و manifest.webmanifest و sw.js والأيقونات) ثم Commit.
3. Settings > Pages > Branch: main / (root) > Save.
4. بعد دقيقة يظهر الرابط: https://اسم-حسابك.github.io/attendance/

## التثبيت على سطح المكتب بأيقونة الشركة
- Chrome أو Edge: افتح الرابط، اضغط أيقونة التثبيت في شريط العنوان (أو القائمة > Install / تثبيت التطبيق)، واختر إنشاء اختصار على سطح المكتب.
